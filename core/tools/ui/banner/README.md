# Banner Configuration for Termux

Customize Termux with W8BDCR-Core-Termux Banner

**Package:** core-termux (banner config)  
**Author:** W8BDCR  
**Repository:** https://github.com/w8bdcr-official/W8BDCR-Core-Termux  
**Type:** Termux UI customization  
**License:** MIT

## Description

Configure a custom banner for Termux using W8BDCR-Core-Termux. This package allows you to set a personalized welcome message that appears when you start Termux, enhancing your terminal experience.

## Dependencies

- Termux (base installation)

## Install

```bash
core install ui --banner
```

## Uninstall

```bash
core uninstall ui --banner
```

## Update

```bash
core update ui --banner
```

## Notes

- Source file: `~/.local/share/core-termux/assets/banner/w8bdcr.txt`
- removes Termux welcome message: motd
- Restart Termux to apply changes
